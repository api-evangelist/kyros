# Kyros College Prep

> Kyros (kyros.ai) is an AI-driven college preparation and admissions platform.
> Per the company's own structured data: "Kyros, a College Prep Platform by
> former Googlers, Admissions Officers, and Professors, uses AI to offer 100K+
> summer and financial aid programs." The platform combines student assessments,
> college and major matching, counseling, essay and recommendation-letter
> support, extracurricular and summer-program discovery, and partner programs for
> schools and employers.

## API surface

Kyros publishes no public API as of 2026-07-19. There is no developer portal,
no API documentation, no OpenAPI or AsyncAPI definition, no MCP server, no
client SDKs, no CLI, and no /.well-known/ discovery documents. DNS resolves no
api., docs., developer., or portal. subdomain on kyros.ai. The web application
is a single-page app served from www.kyros.ai behind Cloudflare; any HTTP
interface it uses is internal and undocumented. Nothing in this file should be
read as describing a consumable public API.
